# Validation Checklist

## Power & POST
- [ ] System powers on
- [ ] Fans spin / pump runs
- [ ] POST successful
- [ ] No error LEDs / beep codes

## BIOS / Hardware Recognition
- [ ] CPU detected
- [ ] RAM detected (correct capacity)
- [ ] Storage detected
- [ ] Fan speeds visible
- [ ] Temps stable at idle

## Thermal / Airflow
- [ ] Radiator exhaust configured correctly
- [ ] Intake fans oriented correctly
- [ ] Cables not blocking airflow
